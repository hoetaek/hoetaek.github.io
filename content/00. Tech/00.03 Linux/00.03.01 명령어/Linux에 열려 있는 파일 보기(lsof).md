## `lsof` 명령어 출력 열(Column) 설명

`lsof` (List Open Files) 명령어는 시스템에서 현재 열려 있는 파일들에 대한 정보를 보여주는 강력한 도구입니다. 여기서 "파일"은 일반적인 데이터 파일뿐만 아니라 디렉토리, 네트워크 소켓, 파이프, 디바이스 등 유닉스 계열 운영체제에서 파일처럼 취급되는 모든 것을 포함합니다.

`lsof`의 기본 출력 형식은 여러 열(column)으로 구성되어 있으며, 각 열은 다음과 같은 정보를 나타냅니다.

### 1. `COMMAND`

- **의미:** 해당 파일을 열고 있는 프로세스의 **명령어 이름**입니다.
    
- **예시:** `nginx`, `sshd`, `bash`, `python` 등 프로세스를 시작한 명령어의 이름이 표시됩니다. 시스템 설정에 따라 전체 경로 없이 명령어 이름만 표시될 수도 있습니다.
    

### 2. `PID`

- **의미:** 해당 파일을 열고 있는 프로세스의 **프로세스 ID (Process ID)**입니다.
    
- **예시:** `1234`, `2206` 등 각 프로세스를 고유하게 식별하는 숫자입니다. 이 PID를 사용하여 `ps`, `top`, `kill` 등의 다른 명령어와 연계하여 프로세스 정보를 확인하거나 제어할 수 있습니다.
    

### 3. `USER`

- **의미:** 해당 파일을 열고 있는 프로세스를 **실행시킨 사용자 이름**입니다.
    
- **예시:** `root`, `www-data`, `nginx`, `ubuntu` 등 프로세스의 소유자 계정이 표시됩니다.
    

### 4. `FD` (File Descriptor)

- **의미:** 프로세스가 파일을 참조하기 위해 사용하는 **파일 디스크립터 번호 또는 식별자**입니다.
    
- **표시 형식:**
    
    - `숫자u`: 일반적인 파일 디스크립터 번호. `u`는 접근 모드(읽기/쓰기)를 나타냅니다. (예: `3u`, `15u`)
        
    - `cwd`: 현재 작업 디렉토리 (Current Working Directory)
        
    - `txt`: 프로그램 코드 (텍스트 세그먼트)
        
    - `rtd`: 루트 디렉토리 (Root Directory)
        
    - `mem`: 메모리 매핑된 파일 (Memory-mapped file)
        
    - `NUMBERr`: 읽기 전용(read) 접근
        
    - `NUMBERw`: 쓰기 전용(write) 접근
        
    - `NUMBERu`: 읽기/쓰기(read/write) 접근
        
- **중요성:** 프로세스는 이 FD를 통해 커널에게 특정 파일에 대한 작업을 요청합니다. 네트워크 소켓도 이 FD로 관리됩니다.
    

### 5. `TYPE`

- **의미:** 파일의 **종류**를 나타냅니다.
    
- **주요 유형:**
    
    - `REG`: 일반 파일 (Regular file)
        
    - `DIR`: 디렉토리 (Directory)
        
    - `CHR`: 문자 특수 파일 (Character special file, 예: 터미널 장치)
        
    - `BLK`: 블록 특수 파일 (Block special file, 예: 디스크 장치)
        
    - `FIFO`: 파이프 (Named pipe)
        
    - `unix`: **유닉스 도메인 소켓 (UNIX domain socket)** - 동일 시스템 내 프로세스 간 통신용 소켓
        
    - `IPv4`: IPv4 네트워크 소켓
        
    - `IPv6`: IPv6 네트워크 소켓
        
    - `LINK`: 심볼릭 링크 (Symbolic link)
        
    - `sock`: 소켓 (일반적인 경우)
        
- **활용:** 이 정보를 통해 해당 FD가 일반 파일인지, 네트워크 연결인지, 파이프인지 등을 구분할 수 있습니다.
    

### 6. `DEVICE`

- **의미:** 파일이 위치한 **디바이스의 번호** (주 번호, 부 번호 형식) 또는 소켓 관련 정보입니다.
    
- **예시:**
    
    - 디스크 파일: `8,1` (주 번호 8, 부 번호 1)
        
    - 네트워크 소켓: 디바이스 번호 대신 프로토콜 관련 정보나 메모리 주소 등이 표시될 수 있습니다.
        
- **참고:** 일반 사용자에게는 `NODE`나 `NAME` 열이 더 직관적일 수 있습니다.
    

### 7. `SIZE/OFF`

- **의미:** 파일의 **크기 (Size)** 또는 파일 **오프셋 (Offset)**을 바이트 단위로 나타냅니다.
    
- **표시 내용:**
    
    - 일반 파일: 파일의 크기
        
    - 네트워크 소켓, 파이프 등: 해당 시점의 큐에 쌓인 데이터 양 또는 0으로 표시될 수 있습니다. TCP 소켓의 경우 송수신 큐(Tx/Rx Queue) 크기를 의미하기도 합니다 (`-T` 옵션 사용 시).
        
    - 블록/문자 장치: 장치에 대한 오프셋 정보.
        

### 8. `NODE`

- **의미:** 파일 시스템에서의 **로컬 파일 노드 번호 (Inode number)** 또는 네트워크 소켓 관련 정보입니다.
    
- **표시 내용:**
    
    - 로컬 파일: 해당 파일의 아이노드(inode) 번호.
        
    - 네트워크 소켓: 프로토콜 제어 블록(PCB) 주소, TCP 상태(LISTEN, ESTABLISHED 등) 또는 기타 네트워크 관련 식별 정보가 표시될 수 있습니다.
        
- **활용:** 아이노드 번호는 파일 시스템 내에서 파일을 고유하게 식별하는 데 사용됩니다.
    

### 9. `NAME`

- **의미:** 파일의 **이름 또는 경로**, 네트워크 연결의 상세 정보 등 파일에 대한 가장 구체적인 식별 정보입니다.
    
- **표시 내용:**
    
    - 일반 파일/디렉토리: 파일 또는 디렉토리의 전체 경로 (시스템 설정이나 `lsof` 옵션에 따라 달라질 수 있음).
        
    - 네트워크 소켓:
        
        - `*:http (LISTEN)`: 모든 IP 주소의 80번 포트(http)에서 리스닝 중.
            
        - `localhost:smtp (LISTEN)`: 로컬호스트의 25번 포트(smtp)에서 리스닝 중.
            
        - `server-ip:443->client-ip:12345 (ESTABLISHED)`: 서버 IP의 443 포트와 클라이언트 IP의 12345 포트 간에 연결이 수립됨.
            
        - `TCP 127.0.0.1:54321->127.0.0.1:9000 (ESTABLISHED)`: 로컬 TCP 연결 정보.
            
    - 유닉스 소켓: 소켓 파일의 경로 (예: `/var/run/php/php8.1-fpm.sock`) 또는 연결 정보.
        
    - 파이프: `pipe` 또는 관련 식별자.
        

이 정보들을 종합하면, 어떤 프로세스(`COMMAND`, `PID`, `USER`)가 어떤 종류의 파일(`TYPE`)을 어떤 방식(`FD`)으로 열고 있으며, 그 파일의 구체적인 정보(`NAME`, `NODE`, `SIZE/OFF` 등)가 무엇인지 상세하게 파악할 수 있습니다.
